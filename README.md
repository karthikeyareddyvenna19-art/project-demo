# SportZone

A sports information web application that allows users to view live matches, upcoming matches, past matches, player statistics, and more.

## Technology

- HTML
- CSS
- JavaScript

## Features

- Display major sports (Cricket, Football, Basketball, Tennis, Formula 1, Baseball, Hockey, Volleyball)
- Select a sport to filter matches
- View live, upcoming, and past matches
- Open match details with scoreboard, commentary, highlight overs, and statistics
- View player statistics
- User profile with favorite sports, teams, and players (using localStorage)
- Search for teams, players, and matches
- Responsive design
- Auto-refreshing scoreboard for live matches
- Simulated commentary feed
- Highlight overs built from key commentary moments

## How to Use

1. Open `index.html` in a web browser.
2. Select a sport from the grid.
3. View matches in the Live, Upcoming, or Past tabs.
4. Click on a match to see detailed information in the match centre.
5. Explore player statistics.
6. Use the search box to find specific teams, players, or matches.
7. Access the profile modal to manage favorites.

## Notes

- The application uses sample data for demonstration purposes.
- In a future version, the sample data can be replaced with data from a sports API.
- The design is responsive for desktop, tablet, and mobile devices.
